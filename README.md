# CSE111 – Java Programming

This repository contains my Java coursework and practice from **CSE111** at BRAC University.

I’m using this repository to keep my assignments in one place and track what I’m learning as I practise Java.

## Repository structure

- **Assignment-01/** – Introductory Java tasks, including loops, arrays, and basic classes
- **Assignment-02/** – Classes, objects, methods, and simple object-oriented programming exercises
- **Assignment-03/** – Constructors, arrays, methods, and class-based programming tasks
- **Ungraded-Tasks/** – Additional practice and ungraded exercises

## Topics covered so far

- Java basics and input/output
- Conditional statements and loops
- Arrays and strings
- Classes, objects, and methods
- Constructors and instance variables
- Basic object-oriented programming

## Notes

- These files are coursework and practice written while learning Java.
- The code has been separated into individual `.java` files so that each public class is in a file with the matching class name.
- The original solution logic has been kept as submitted; this repository is an organised record of my learning, not a claim that every solution is fully polished.
- Some classes are designed to be used with separate tester programs provided in class.

More coursework and projects will be added as I continue learning.
